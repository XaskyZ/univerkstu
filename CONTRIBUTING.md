# Как внести вклад

Спасибо за интерес к проекту! PR и issues приветствуются.

## С чего начать

1. Форкните репозиторий и создайте ветку от `main`:
   ```bash
   git checkout -b feature/краткое-описание
   ```
2. Поднимите проект локально — см. [README](./README.md#локальный-запуск).
3. Внесите изменения, добавьте/обновите тесты.

## Перед отправкой PR

Прогоните проверки в затронутой части:

```bash
# backend
cd backend && npm run build && npm test

# frontend
cd frontend && npm run build && npm test && npm run lint
```

PR должен проходить сборку и тесты. Старайтесь держать изменения
сфокусированными: один PR — одна логическая правка.

## Стиль

- TypeScript везде; следуйте существующему стилю соседнего кода.
- Именование, отступы и структуру берите из окружающего файла.
- Комментарии — по делу, там где логика неочевидна.

## Что стоит знать

- Приложение работает с порталами вуза (KSTU/Platonus). Полноценно
  протестировать парсеры без учётной записи студента не выйдет — по возможности
  покрывайте логику юнит-тестами с фикстурами (как в существующих `*.test.ts`).
- Секреты только через `.env` (см. `.env.example`); настоящий `.env` в
  `.gitignore`.

## Issues

Нашли баг или есть идея — откройте issue с кратким описанием и шагами
воспроизведения. Скриншоты приветствуются.
