# UniverKstu

Персональный веб-сервис (PWA) для студентов КарГТУ (KSTU): расписание, экзамены,
УМКД, оценки из Platonus, профиль, группы и соцлента. Приложение логинится в
порталы вуза под учётной записью студента, парсит данные в структурированный вид
и кэширует их, добавляя поверх собственные фичи (группы с ролями, доска
объявлений, чаты, push-уведомления).

## Стек

| Слой | Технологии |
|---|---|
| **Frontend** | Next.js 16 (App Router), React 19, TypeScript, Tailwind v4, PWA, тема на CSS-переменных |
| **Backend** | Fastify, TypeScript, axios + cheerio (парсеры порталов), Postgres/Supabase, Cloudflare R2 (файлы), JWT + сессии устройств, Web-Push (VAPID) |

```text
frontend/   Next.js — почти целиком клиентское приложение, SSR под метаданные
backend/    Fastify — прокси/парсер порталов вуза + собственные фичи и хранилище
docs/       Референс-документация по слоям (см. docs/reference)
```

## Возможности

- 📅 **Расписание** — парсинг из портала/Platonus, чётность недель, каникулы
- 📝 **Экзамены** — сессия, даты, вехи-дедлайны
- 🎓 **Оценки** — рубежки/рейтинг/итог из Platonus, цель-ассистент, уведомления
- 📚 **УМКД** — материалы дисциплин, экзаменационные вопросы
- 👥 **Группы** — роли (староста/куратор/координатор), задачи, файлы, объявления
- 💬 **Чаты и соцлента** — глобальный чат, личные сообщения, реакции
- 📢 **Доска объявлений** — купля/продажа/услуги/потеряшки внутри вуза
- 🔔 **Push-уведомления** — оценки, расписание, задачи (Web-Push)

## Локальный запуск

Требования: Node.js 20+, доступ к Postgres (можно Supabase). Полноценная работа
парсеров требует учётной записи студента KSTU/Platonus — без неё поднимутся сами
приложения, но данные из порталов подтянуть не выйдет.

### Быстрый старт (оба приложения)

```bash
npm install          # в корне — ставит concurrently
npm run dev          # запускает frontend + backend
```

### Backend отдельно

```bash
cd backend
cp .env.example .env         # заполните свои значения
npm install
npm run dev                  # dev-сервер
npm run build                # сборка (tsc)
npm test                     # тесты (vitest)
```

Обязательные переменные: `JWT_SECRET`, `ENCRYPTION_KEY`, строка подключения к
Postgres. Остальное — см. комментарии в `backend/.env.example`.

### Frontend отдельно

```bash
cd frontend
cp .env.local.example .env.local   # укажите NEXT_PUBLIC_API_URL
npm install
npm run dev
npm run build
npm test
npm run lint
```
